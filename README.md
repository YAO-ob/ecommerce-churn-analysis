# 电商平台客户流失分析与用户画像

## 项目简介
基于电商平台 5630 条客户行为数据（19 个维度），完成数据预处理、清洗、特征工程与用户画像可视化分析，识别高流失风险客户特征，为精细化运营与流失预警提供数据支撑。

## 数据来源
本数据集来源于阿里云天池公开数据集（E Comm 客户流失数据集），仅供学习与研究使用，非商业用途。如需获取原始数据，可前往阿里云天池数据平台检索下载。

## 技术栈
Python · Pandas · NumPy · Matplotlib · Seaborn · Jupyter Notebook

## 分析流程
1. 数据预处理：中英文列名映射、分类取值标准化、列序校验
2. 数据清洗：缺失值分级处理、IQR 异常值检测与缩尾
3. 特征工程：衍生活跃度、消费水平、使用频率、满意度分组 4 个特征
4. 可视化分析：用户基本特征与行为特征画像

## 核心结论
- 流失客户占比 16.84%
- 主力用户画像：一线城市、已婚、40-49 岁男性、手机端
- 数据经清洗后有效样本 4081 条

## 文件结构
- 电商数据预处理.py：数据标准化脚本（含单元测试）
- 电商数据分析.ipynb：分析主文件
- 电商行为数据.xlsx：处理后的标准化数据
