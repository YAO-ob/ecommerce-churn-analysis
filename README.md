# 电商平台客户流失分析与用户画像

## 项目简介
基于电商平台 5630 条客户行为数据（19 个维度），完成数据预处理、清洗、特征工程、用户画像可视化与流失特征交叉分析，识别高流失风险客群，为精细化运营与流失预警提供数据支撑。

## 数据来源
数据集来源于阿里云天池公开数据集（E Comm 客户流失数据集），仅供学习与研究使用，非商业用途。如需获取原始数据，可前往阿里云天池数据平台检索下载。

## 技术栈
Python · Pandas · NumPy · Matplotlib · Seaborn · OpenPyXL · Jupyter Notebook

## 分析流程
1. 数据预处理：中英文列名映射、分类取值标准化、列序校验
2. 数据清洗：缺失值分级处理（少量缺失删行、数值中位数填充、分类众数填充）、IQR 异常值检测与缩尾
3. 特征工程：衍生活跃度、消费水平、使用频率、满意度分组 4 个特征
4. 可视化分析：用户基本特征与行为特征画像
5. 流失特征分析：按各分组维度统计流失率，对比流失组与未流失组的数值特征差异

## 核心结论
- 整体流失率 16.79%（流失 685 人 / 有效样本 4081 条）
- 高流失特征客群：单身客户流失率 26.1%，三线城市 20.8%，60 岁以上 36.6%、50–59 岁 23.9%；功能机/平板端用户流失率高于手机端
- 流失用户平台使用时长中位数仅 1 个月，明显低于未流失用户的 9 个月，新用户留存是重点关注方向
- 低流失客群：已婚（11.4%）、一线城市（14.4%）、20–29 岁（8.8%）流失率相对较低

> 注：以上比例基于清洗后的 4081 条有效样本统计；原始数据集为 5630 条。

## 复现步骤
1. 安装依赖：`pip install -r requirements.txt`
2. （可选）运行预处理脚本，由原始数据生成标准化数据：`python 电商数据预处理.py`
3. 打开 `电商数据分析.ipynb`，按顺序运行全部单元即可复现分析过程与图表。

## 文件结构
- `电商数据预处理.py`：数据标准化脚本，含列序校验、取值转换与自测函数
- `电商数据分析.ipynb`：分析主文件，包含清洗、特征工程、画像与流失分析全过程
- `电商行为数据.xlsx`：标准化后的数据（notebook 输入）
- `data/Project Dataset.xlsx`：天池原始数据集
- `outputs/`：分析图表输出截图
